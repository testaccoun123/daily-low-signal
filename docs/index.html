Low Signal Uploader

▶ Uses YouTube API Services to upload our videos to our own YouTube channel.

Low Signal Uploader is the channel owner's internal tool. It uploads the channel's own videos to the channel's own YouTube account with the YouTube Data API (videos.insert). It has no other users and does not access any other YouTube data. By using it, the user agrees to the YouTube Terms of Service; see the Google Privacy Policy.
